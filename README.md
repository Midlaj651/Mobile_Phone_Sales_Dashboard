
# 📱 Mobile Phone Sales Dashboard | Excel

## 📌 Project Overview

<img width="1094" height="720" alt="image" src="https://github.com/user-attachments/assets/a2264ddd-4ce3-4f9d-a6b5-0f3423695dd1" />

The Mobile Phone Sales Dashboard is a data analytics project designed to analyze mobile phone sales across different countries, brands, operators, and distributors.

The dashboard provides insights into sales performance, average unit cost, yearly profitability, and geographical sales distribution. Interactive filters allow users to explore the data by year, brand, operator, distributor, and country.

## 🎯 Project Objectives

- Analyze total mobile phone sales.
- Compare sales performance across mobile brands.
- Identify top-performing distributors.
- Analyze sales by country.
- Compare operator-wise sales performance.
- Monitor average unit cost by brand.
- Track yearly profit trends.
- Provide insights to support business decisions.

## 📊 Key Performance Indicators (KPIs)

- **Total Countries:** 24
- **Total Brands:** 6
- **Total Operators:** 5
- **Total Distributors:** 6
- **Average Unit Cost:** 541.534

*Note: KPI values are based on the dashboard screenshot.*

## 📈 Dashboard Features

### 1. Brand-Wise Sales
- Compare sales across Apple, LG, Samsung, Motorola, Nokia, and Huawei.
- Identify brands contributing the most to total sales.
- Understand the distribution of sales among mobile brands.

### 2. Country-Wise Sales
- Analyze sales across different countries.
- Compare country-level sales performance.
- Identify geographical sales opportunities.

### 3. Distributor-Wise Sales
- Compare sales across distributors.
- Identify high-performing distribution partners.
- Evaluate distributor contributions to total sales.

### 4. Operator-Wise Sales
- Analyze sales across mobile operators.
- Compare operator performance.
- Identify operators contributing significantly to sales.

### 5. Average Unit Cost by Brand
- Compare average unit costs across mobile brands.
- Understand differences in unit costs between brands.

### 6. Year-Wise Profit
- Track profit trends from 2018 to 2021.
- Compare profitability across years.
- Identify changes in yearly financial performance.

## 🎛️ Interactive Filters

The dashboard includes the following filters:

- Year: 2018–2021
- Brand
- Operator
- Distributor
- Country

These filters allow users to explore sales and profitability across different business dimensions.
